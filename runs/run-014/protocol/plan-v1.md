# Main protocol, version 1

Fixed before the main embedding retrieval or score analysis. The time and commit are in events.jsonl and Git. Topic selection is complete in protocol/topic-selection.md. This is a measurement-validation study, not an evaluation of ecological restoration success.

## Question, readers and tests

Do concurrent reference plots or control adjustment improve transfer of annual satellite-embedding tree-cover transition screening to later years and held-out regions, compared with fixed-reference cosine scores and supervised comparators? The intended decision is whether a reference-proximity score warrants use as a screening measurement before field validation. No benefit to users or reduction in field visits is measured.

The proposed success condition is higher held-out recall at a similar false-positive rate. Primary comparisons are (i) control-adjusted versus start-year-fixed reference and (ii) concurrent versus start-year-fixed reference, separately for tree gain and loss in both embedding systems. Test thresholds are fixed using earlier negative examples. Report sensitivity and false-positive rate separately; Youden's J (sensitivity minus false-positive rate) is a descriptive joint summary, not an assumed social cost function. A correction that only changes smoothness or ranking by construction is not evidence of better screening. There is no directional success guarantee or significance-based stopping rule.

## Sampling fixed before representation analysis

Seed 14014. Limit labels to Trees, Grass/forb/herb and Shrubs, and to the four adjacent year-pairs above. Exclude any point within 10 km geodesic distance of the pilot coordinate (-119.6, 37.7). No linkage to people, owners or businesses is performed.

Reference/control pool: all eligible plots labelled Trees in both 2017 and 2018. This pool is selected using only baseline labels, not later outcomes. It represents persistent dominant tree cover over one baseline pair, not verified native/reference forest ecosystems. No future stability filter is allowed. The separate land-use CSV has no matching coordinates in this pool, so forest land use cannot be confirmed; do not silently equate tree cover with forest. These plots are excluded from all target samples. Retrieve 2017–2021 for them. They are not included in supervised fitting or threshold calibration. Allocate half to the centroid reference set R and half to independent controls C by deterministic hash of seed and coordinates. Primary allocation uses seed 14014; seeds 14015–14018 are preplanned reference-allocation sensitivity analyses using the same raw data.

Targets: retain every eligible gain (Grass/Shrubs to Trees), every eligible loss (Trees to Grass/Shrubs), and every stable Trees pair in 2018–2020. Within each before-year, retain up to 16 stable Grass and 16 stable Shrub pairs, and up to 8 pairs in each Grass-to-Shrub and Shrub-to-Grass direction, selected by ascending SHA-256(seed, coordinates, year). Retain fewer if fewer exist. No sample replacement after retrieval outcomes. Target rows and point-years are deduplicated. Retrieve before and after years. Sampling counts must be generated from code and reported, rather than assumed from the pilot notes.

The gain task is conditional on initially Grass/Shrubs; positive means subsequently Trees, negative means subsequently Grass/Shrubs. The loss task is conditional on initially Trees; positive means subsequently Grass/Shrubs, negative means subsequently Trees. This use of known initial cover is part of the task definition. Initial classes and class restrictions limit real-world applicability. Non-tree transitions remain gain-task negatives. Do not estimate population precision or nationally weighted prevalence from this sample.

## Held-out evaluation

Project eligible target coordinates to EPSG:5070 and create five contiguous Voronoi regions by KMeans, n_clusters=5, n_init=20, random_state=14014. Fit regions on coordinates only, before embeddings; save centres and assignments. Assign reference/control coordinates to their nearest centre. For each outer fold, test only later pairs with before-year 2019 or 2020 in that held-out region. Fit and calibrate only earlier pairs (before-year 2017 or 2018) outside that region. Exclude all R/C points in the held-out region. Contemporary unlabelled embeddings of the baseline-selected R/C plots are allowed: this is retrospective monitoring once that year's imagery exists, not forecasting future cover.

Within earlier eligible pairs outside the region, use a deterministic hash of 5-degree longitude/latitude grid cells to reserve approximately 30% of cells for threshold calibration; the other cells fit supervised models. A cell's hash, rather than a label or score, determines allocation. If fewer than 10 negative calibration cases occur for a task/fold, report that fold as unavailable for all methods of that task instead of changing the split. Require at least 8 valid reference and 8 valid control plots per fold/year pair; unavailable folds are reported. Do not choose regions, seeds, samples or thresholds by test results. Each later target is tested once. Earlier targets are never counted as test evidence.

Primary data are complete cases with finite nonzero centre vectors for both years in both models. Report availability by year, class, region and model, including all exclusions. Model-specific complete-case estimates are a secondary availability sensitivity. Reference/control availability is checked per model/pair and recorded. No exclusion based on score size or correctness is allowed.

## Scores and comparisons

Normalize every decoded embedding vector to unit Euclidean norm. Let u_a,u_b denote a target's vectors and r_a,r_b the normalized means of valid R vectors in the corresponding years, outside the held-out region. For the pooled reference, normalize the mean of the available unit reference vectors from both years (equal weight to years, not unequal missing-pixel counts). Define:

* start-fixed: (u_b-u_a) dot r_a;
* end-fixed: (u_b-u_a) dot r_b;
* pooled-fixed: (u_b-u_a) dot normalize(r_a+r_b);
* concurrent: u_b dot r_b minus u_a dot r_a;
* control-adjusted: start-fixed minus the mean start-fixed change of independent C plots;
* standardized-concurrent: z_b-z_a, where z_y = (u_y dot r_y - mean_C[u_Cy dot r_y]) / sample-SD_C[u_Cy dot r_y]. If SD <= 1e-8, mark unavailable, not zero.

Use these scores for gain and their negatives for loss. A constant control subtraction cannot change within-fold/year rankings; explicitly verify/count this identity, and distinguish it from threshold transfer across year pairs. Reference/control summaries must use no target outcome labels. Global references are primary. As a geographic-boundary sensitivity, repeat unsupervised scores using the nearest 8 valid R and nearest 8 valid C plots to each target, still outside its held-out region; require 8 of each, record distances. These are nearest available tree-cover plots, not ecologically matched local forests.

Supervised comparisons receive the same earlier target labels, training/calibration partition, vectors and held-out evaluation:

1. State random forest: predict Trees versus Grass/Shrubs from a single year's embedding; fit both states of each training pair, weights 0.5 per state, 300 trees, min_samples_leaf=3, max_features='sqrt', class_weight='balanced_subsample', random_state=14014, n_jobs=1. Its gain score is P(Trees|u_b)-P(Trees|u_a), loss score its negative. Deduplicate identical plot-year rows if necessary.
2. Direct change gradient boosting: separate binary gain/loss classifiers on concatenated [u_a,u_b,u_b-u_a], HistGradientBoostingClassifier, max_iter=150, learning_rate=.05, max_leaf_nodes=7, min_samples_leaf=10, l2_regularization=1, early_stopping=False, random_state=14014. Use class_weight='balanced' if supported by the pinned installed version. No test tuning or automatic hyperparameter search. Its score is positive-class probability.

For each task, method and fold, set the threshold at the 90th percentile of negative calibration scores (numpy quantile method='higher'); flag scores strictly greater than the threshold. Ties make achieved calibration false-positive rate no greater than the nominal 10%. Save all thresholds and achieved calibration rates, then evaluate later test rows without re-fitting. Also report AUROC as a ranking diagnostic, not a substitute for transferred operating-point performance. No “best correction” is chosen on test data.

## Outcomes, uncertainty, trivial cases and support

Primary displays: numbers of positive/negative test cases; sensitivity, false-positive rate, J, and paired differences in J relative to start-fixed; report both main comparisons for both tasks/models, without discarding failures. Aggregate predictions across held-out regions; show year-pair and region heterogeneity without ranking named regions. Use 2,000 paired spatial block bootstrap resamples of the later test rows, blocks defined by the same 5-degree cells, random_state=14014. Interval endpoints are 2.5/97.5 percentiles, conditional on fitted scores and the fixed reference pool. Do not claim independent future-year uncertainty from only two later year-pairs. Missing-class bootstrap resamples are excluded and their number reported. Estimates across methods remain paired.

Count all score-equality cases (absolute tolerance 1e-8), unchanged flags, positives/negatives, score ties at thresholds, reference/control exclusions, reference-anchor direction disagreements, and sign reversals for which both absolute changes exceed .01 cosine units. The .01 threshold is a prespecified descriptive scale, not validated ecological importance. Report year/fold groups for which control subtraction necessarily preserves ranking. Zero improvement, ceilings, floors and small gain denominators must remain visible in the abstract/results where material.

Retrieve 3x3 patches when possible. Centre-pixel scores are primary. A preplanned support sensitivity uses normalized means of valid decoded pixel vectors, requiring all nine pixels; repeat the primary method comparisons and supervised baselines. TESSERA patches are native approximately 30x30 m; the geographic AlphaEarth mosaic's 3x3 footprint is latitude-dependent and is not exactly 30x30 m. Record approximate footprint and geolocation metadata. Additional native AlphaEarth COG checks, if conducted, require a protocol addendum before their measurements and will be described as secondary. Stable dominant cover is not ecological stability, and different support and annual timing can attenuate change detection.

## Repetitions, retrieval, stopping and analysis order

The deterministic primary split is one study with five spatial test folds; 5 seeds are reference-allocation sensitivity, not 5 independent replications. Two representation systems test whether conclusions are limited to one embedding implementation. No human experiment or self-model output is used as experimental data. The one candidate critique API call is solely topic-selection infrastructure; no further paid AI calls are planned.

Run preparation once after committing this plan. Retrieve in deterministic point/year hash order in bounded batches; save each successful patch immediately and reuse it. Set each batch timeout <=1800 seconds. Start with at most 64 point-years per process; batch size may decrease for elapsed-time management, never based on performance. Transient network errors may retry at most 3 attempts; log each attempt. Keep original failed/timeout experiment folders. No more than two experiment processes at once. Stop downloading at 8.5 GiB, or 17:00 UTC on 2026-10-25, leaving time for analysis/writing; record incomplete retrieval rather than selecting favourable completed cases. Do not start a batch unlikely to finish in its 30-minute limit or before the stop time. Never start new long experiments in the final hour before the research deadline (20:12:56 UTC).

Analyse only after the planned retrieval is complete or formally stopped, preserving missingness. Generate numbers for tables, figures and paper from saved analysis outputs with a single offline script. Save raw outputs and explicit code/plan/input hashes. Commit the end of each main experiment. After the first results, investigate alternative explanations and relevant generalization while >=2 hours remain, using versioned amendments fixed before any new tests; label new metrics/hypotheses exploratory if decided after observing results. Do not replace an unsuccessful study with a new question.

## Safety and limits

Passive public environmental data only, no individuals, ownership linkage, security testing, human participants, external publication or contact. No disclosure issue is anticipated. Report aggregate comparisons with the sample/definition/timing limitations alongside them. Policy value judgments and ecological restoration outcomes are beyond what the labels can establish. All unforeseen changes go into protocol/deviations.md with tool-obtained times and event IDs; do not overwrite this plan.
