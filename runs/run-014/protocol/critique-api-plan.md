# Authorized candidate critique — pre-call plan

Purpose: the single critique of five topic candidates required by research-question step 6. This is not an experimental observation and not the later paper review. No other model will perform research work. Provider: OpenAI. Exact requested model: `gpt-6-astra`; reasoning `xhigh`. A local model is not a substitute because the run instructions specify this model.

Calls: one `client.responses.create`, at most one resend after failure; no SDK automatic retries. Background mode, status checked with retrieve, stored whole JSON. If stopped pending, cancel. Web tool as required; fallback without web only if unsupported. Prompt is copied exactly from the skill code block except the five candidate entries, ordered by candidate ID. Entries contain only question, outline and closest work/difference. No scores or preferred candidate are sent. The score table must be committed first.

Input: original candidate descriptions and public bibliographic metadata only; no key, household, patient or confidential data. The prompt will be checked before sending. Source browsing and tools are not delegated beyond this explicitly authorized critique.

Output limit: omitted as explicitly required by step 6. Consequently there is no user-set finite maximum output-token limit or deterministic maximum-call estimate; this call is explicitly exempt from the pre-call maximum-cost check. The model's published output capacity is 128,000 tokens; this is not an estimate of actual use. The wrapper confirms existing actual expenditure is below USD 20, records this exception and computes actual expenditure from returned usage. No unbounded experimental API sequence is authorized.

Prices checked 25 October 2026 from official OpenAI model/pricing pages; snapshots are in `sources/openai-pricing.md` and `sources/openai-gpt-6-astra.md`. Web search USD 0.01 per search item, plus search content at model input rates. Output includes billed reasoning tokens. Set service tier `default`; no cache-write mode, paid container or other tool requested. Actual cost, failures, tokens and search-item count go into `api_calls.jsonl`; the latest row for each call ID is the accounting record. Pending rows with unknown usage are not treated as zero-cost final calls.

Terms checked 25 October 2026: OpenAI Services Agreement (effective 1 January 2026), Sections 3.3 and 4. Source: https://openai.com/policies/services-agreement/ (opened through web tool; relevant passage saved in sources/search-022.txt). Restrictions include competing-model development and rate-limit circumvention; neither is involved. No outputs will train another model. Inputs are researcher-created public-topic descriptions. The supplied API credential's value is used only from its environment variable, is excluded from request bodies, command-line arguments and logs, and is never displayed.

Analysis: verify every cited close work independently before using it; label each critique point adopted/not adopted with reason. Ignore any ranking or new-topic suggestions as adoption grounds. Preserve the original scores and append changes. The critique's existence is a limitation of autonomous topic selection, not independent validation of the paper.
