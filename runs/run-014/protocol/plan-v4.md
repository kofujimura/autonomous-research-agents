# Version 4 — a new reference sample and a longer temporal horizon

This is an additive secondary generalization test, fixed before any main score outcomes have been calculated or inspected. V1 remains the primary experiment. The original study, pilots and failures are not replaced. Reason: the original released LCMAP pairs provide only two later annual test pairs and few tree-gain cases. The newly accessed Annual NLCD reference sample offers different plots, annual labels through 2023 and alternate interpretations. Its endpoint definition is different and must remain explicit.

## Question and data

Do the earlier-calibrated reference/control and supervised readouts retain their behaviour in a separate public human-interpreted sample, including calendar pairs beyond the original label horizon? This tests transfer across a reference sample and ontology as well as time. It is not an exact replication of the dominant-Trees endpoint or a new ecological-restoration outcome.

Input: USGS Annual National Land Cover Database Collection1.0 Reference Data Product, DOI10.5066/P13EDMAF, official MRLC public ZIP, Last-Modified29April2026. The original tabular members, archive index, CRC32 and SHA-256 are saved under data/nlcd/; official full metadata is sources/nlcd-metadata.xml. Reuse is unrestricted/public domain, checked25October2026. Range access reads only the openly linked tabular members; it does not bypass the ScienceBase403 response. No full raster is downloaded. Retain only environmental fields in analysis; do not read free-text change notes or link to owners or businesses.

NLCD **Forest** means at least20% vegetation cover as trees taller than5m. Shrubland includes young trees under5m. Herbaceous generally exceeds80% vegetation and excludes intensive cultivation. This differs from LCMAP's majority-percentage Trees class, which includes standing dead trees. Name the extension endpoint **Forest-class transition**, not the same tree-cover definition. The computational crosswalk Forest→Trees, Shrubland→Shrubs and Herbaceous→Grass/forb/herb is solely for applying the already defined readouts/task machinery; keep all original labels. Exclude other classes, including wetlands and cultivated cover, rather than pretending they are equivalent.

## Fixed sample and exclusion rules

Use adjacent pairs2019–2020,2020–2021,2021–2022 and2022–2023. Join consecutive annual records by plotid and year, require both primary labels in Forest/Herbaceous/Shrubland. Convert the supplied pixel-centre x/y coordinates using the WGS84 Albers CRS supplied in the .prj member (not silently substituting a NAD83 CRS). Exclude the pilot10km neighbourhood and every new plot within1.28km geodesic distance of any v1 target, v1 reference/control or v2 non-tree control. This prevents coincident/nearby plot reuse; report actual counts and distances. Assign v1's geographic regions from its fixed EPSG:5070 centres without re-fitting them.

Retain every eligible Forest gain (Herbaceous/Shrubland→Forest) and Forest loss (Forest→Herbaceous/Shrubland). For each before-year, select up to50 stable Forest,25 stable Herbaceous and25 stable Shrubland pairs, and up to8 pairs in each Herbaceous↔Shrubland direction, by ascending SHA-256(14014,'nlcd_sample',plotid,before_year). If a plot contributes multiple pairs, keep them and count unique plots separately. Bootstrap entire5-degree spatial cells, which contain every observation of a plot; never treat repeated years as independent plots. This enriched sample does not estimate national transition frequency, precision or a ranking of regions.

No new target labels enter fitting or threshold calibration. Earlier2017–2018 and2018–2019 LCMAP fitting/calibration sets, their five region holdouts, the reference/control allocation and all original model parameters remain unchanged. ## Analysis

For each region apply readouts fitted/calibrated on earlier LCMAP pairs outside it to the new target pairs inside it. Recompute contemporaneous reference/control summaries from the same baseline-selected plot cohorts at the required year, without using any new outcome label. Apply the **same earlier thresholds**: verify equality with the saved v1/v2 thresholds to numerical tolerance1e-12. If a ref/control summary is unavailable, report exclusions instead of changing its rule. State-random-forest and direct-gradient-boosting models are refitted deterministically from exactly the same earlier inputs/labels, with no NLCD training or tuning.

Primary extension readouts are v1's six global reference/control scores and its two supervised baselines, plus v2's global non-tree control adjustment for gains and frozen2017-reference variants. Use primary allocation seed14014 and centre pixels; patch means are a support sensitivity. No best method is selected on extension results. Retain original target labels alongside the crosswalk. The primary report uses primary_cover; a prespecified label-uncertainty sensitivity keeps only pairs whose alternate_cover equals primary_cover in both years. Describe differences in availability and compare methods on common rows.

Report sensitivity, false-positive rate,J and paired differences relative to the start-year reference, with the same2,000 paired5-degree-block bootstrap and seed14014. Group results separately into (a)new plots in the overlapping2019/2020 before-years and (b)new plots beyond the original horizon in2021/2022. Also show each calendar pair. Never combine this endpoint's estimates with the original LCMAP estimates as if labels and sampling were the same. Preserve different denominators and report all null/harmful corrections. All computations must be possible offline from saved measurements.

## Limits and stopping

This extension broadens sample, time and label definitions simultaneously; any difference cannot be attributed to time alone. Both samples use image interpretation and may share satellite inputs; neither is ecological field ground truth. A positive transfer result would still not validate ecological restoration success. Label ambiguity and few gains remain possible. Stop if data retrieval cannot finish by17:00UTC or storage approaches8.5GiB; report an incomplete extension rather than redefining the sample. This addition is based on data availability and the pre-existing small-gain/horizon limitation, not on observed method performance, and is recorded as a secondary pre-analysis amendment.
