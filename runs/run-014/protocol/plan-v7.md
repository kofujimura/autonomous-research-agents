# Version 7 — established embedding readouts before score inspection

Fixed before any empirical readout/prediction results are inspected. A repeated prior-work search and the original AlphaEarth change-detection methods identify two additional comparisons that require no new data. The original hypotheses and all existing readouts remain intact.

1. **Cosine change magnitude:** score 1-u_a·u_b, positive for either gain or loss. Unlike directed reference scores, do not negate it for the loss task. This established baseline detects any large angular change without requiring a forest direction. It uses the same earlier negative calibration, region holdouts, nominal10% false-positive rule, unit vectors and centre/patch supports. It is independent of reference allocation; repeats under reference settings are not independent replications.
2. **Subsequent-reference similarity:** score u_b·r_b for gains and its negative for losses. Since the initial class is supplied, this checks whether subtracting an initial similarity is helpful relative to simply classifying subsequent cover with a centroid. Apply the same reference/availability rules, calibration and geographic sensitivities as the existing reference scores. It does not measure change where the initial class is unknown.

Include both in v1 and v4 reports, without choosing a winner from test results. The magnitude baseline is standard prior work, not a new method. The conditional nature of every case remains explicit as in v6. These additions strengthen comparisons before results; they do not alter sampling, primary reference/control contrasts, thresholds, paid usage or resource limits. Full outcome tables retain every readout even if a figure shows a labelled subset for readability.

The search also located a class-restricted change-screening study in a hyper-arid region and a registered coral-reef embedding evaluation. Only search/abstract-level material is currently checked for those two; access restrictions are retained and neither is evidence for factual scientific claims unless relevant full text is subsequently checked. No novelty assertion is made. The full-text Wheeler et al. review provides context on field validation of remote-sensing carbon measurements; this study does not evaluate carbon-credit standards or carbon stocks.
