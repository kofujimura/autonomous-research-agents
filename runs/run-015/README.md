# Free Research015: spatial temperature-exceedance probabilities from ensemble summaries

**Final revised study after one review by an AI agent.** The first draft remains at local tag `submission-1`; the final submitted commit is resolved by tag `final`. The primary empirical results are unchanged. `review/response-1.md` addresses all seven review findings, with finite-member/exact-moment and geometry qualifications, fuller certification reporting, literature positioning and labelled post-review diagnostics. The city acquisition calendar remains partly unfinished. Conditions, deadlines and intervention records are in `manifest.json`.

The study audits which spatial temperature-exceedance count probabilities can be certified from individual probabilities, an aggregate second moment or all pairwise probabilities. Its reference is each retained operational ensemble's empirical distribution. It does not measure observed weather skill, health effects, real service capacity, adoption or realized economic value.

## Data and code

`data/weather/` contains original selected-site vectors, per-member provenance and indexes. `data/weather-v4/` contains the separately acquired city/time vectors; `data/weather-v4-derived/` holds member-aligned snapshots/maxima. New extraction of an overlapping forecast is an extraction check, not an independent forecast sample, and does not silently fill an exhausted original unit.

Complete global temperature messages were decoded for extraction. Apart from a small set retained solely as offline decoder-validation fixtures in `data/extraction-validation/`, outside-site values were not retained and are not scientific analysis variables. The lossless selected vectors are the bundled raw analysis inputs. Their metadata record original URLs, index offsets/lengths, global field hashes, dates, members, units and selected grid positions. The full optional IFS mask and Natural Earth archive are bundled. All failed transfers, partial members and experiments remain referable; missing outputs are not fabricated.
