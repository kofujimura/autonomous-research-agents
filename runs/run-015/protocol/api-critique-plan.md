# Permitted topic-critique API call (before execution)

Purpose: the one candidate critique required by research-question skill step 6. This is not a main experiment, literature summarisation service, research agent, or review. Local/public models are not a substitute because the run instructions require the exact critic `gpt-6-astra` with reasoning effort `xhigh`.

Provider/model: OpenAI Responses API, model `gpt-6-astra`, effort `xhigh`, `background=True`, web search enabled and source-list inclusion. Standard service tier is requested to make the official rates applicable. Default 30-minute implicit cache pricing is used. No temperature or seed is set (unsupported/custom stochastic controls are not assumed). No output-token limit is set, as explicitly required by the skill. The first call is made only after the scores have been committed. A second generation call is permitted only after a failed first call, with web search omitted only if unsupported; no model/effort substitution. SDK retries are disabled. Poll/retrieve operations are not generation calls. Maximum two generation attempts, no automatic resends.

Input: the exact copied critique template with only its final candidate-list placeholder filled. The candidate list includes only question, method outline, closest prior work and difference for C01/C02/C05/C06/C07, in ID order. No scores, preferences, rankings, full log, secrets, private data or personal information are sent. Public bibliographic titles/DOIs and this agent's own proposals are the only external information in the prompt. All request/response JSON and the extracted critique will be retained.

Input token maximum: no additional numerical limit specified; the fixed request text is saved for inspection, and actual token usage is recorded from the response. Output maximum/estimated cost: not bounded in the request and not guessed. The skill explicitly exempts this critique from the pre-call maximum-cost check and asks for actual cost only. This exception is recorded by the wrapper; the full $20 cumulative budget remains in force and no further call is made if the recorded cost exhausts it. The wrapper checks that the cumulative known cost is below $20 and that there are no earlier unresolved-cost generation attempts before starting a request. No other AI API experiment is planned.

Official prices checked in this run (UTC 2026-10-25): standard short-context input $10 / million, cached input $1 / million, 30-minute cache writes $12.50 / million (total rate, not a surcharge), 12-hour cache writes $25 / million, output including reasoning $50 / million; long-context input/cache rates double and output is $75 / million above the stated 272K threshold. Web search $10 / 1000 search calls plus content tokens charged at model rates. The response's usage and the number of `web_search_call` output items determine the computed actual cost. Cache-write details are accounted for separately from ordinary and cached input tokens. If billing details are missing or inconsistent, record the cost as unknown; do not invent token counts or invoice totals.

Sources: `literature/openai-pricing.md`, `literature/openai-astra.md`, `literature/openai-prompt-caching.md`, `literature/openai-background.md`, `literature/openai-web-search.md`. Source URLs, retrieval times and hashes are in `sources.jsonl`. The official services agreement (effective January 2026) and data-controls documentation were checked; the critique will not be used to train competing models, and no service limits or safety measures are bypassed.

Analysis: classify each critique point as adopted/not adopted with reasons. Independently confirm any newly named prior work before using it. Ignore any ranking or new-topic proposal as a basis for selection. Keep initial scores and append revisions. Identify the model actually returned and date of use. A completed response is required before evaluating the full critique; truncated/failed output alone is not used for topic selection. This is consultation during topic selection and will be stated as a limitation in the paper.

All API operations use only `scripts/ai_api.py`, which reads the designated key from the environment, stores no credentials, saves pending/final records, computes cost from saved usage/prices and enforces the attempt cap. It saves a background response ID immediately so a continuation can retrieve or cancel the same request. After 25 minutes a still-running request is cancelled, to remain within the 30-minute process/resource rule. No background agent is launched.
