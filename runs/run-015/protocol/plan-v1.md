# Plan v1: dependence information for pooled temperature-exceedance decisions

This plan is fixed before main data acquisition or analysis. The author is this session's research agent. Topic-selection critique is complete; no AI API is planned for experiments, annotation, code, interpretation or writing. Changes will use new versions and a deviation log. Pilot initializations 2026-07-01 and 2026-07-02 are excluded from the main study. The pilot's measured outcomes are feasibility evidence only.

## Question and scope

On equally sized operational machine-learned and physics-based weather ensembles, when do reusable site and pairwise co-exceedance summaries determine pooled temperature-exceedance capacity decisions for user-chosen regional portfolios, and when is a portfolio-specific count distribution or member-coherent forecast still required?

The intended reader decision is whether an interface giving low-order dependence information is sufficient for these flexible queries. No actual provider's bandwidth constraint, product demand, operational capacity, health effect, calibration or forecasting superiority is measured. A portfolio-specific count distribution is exact and compact when that portfolio is known. The study must include it and must not claim a scalar moment is a better product in that situation.

The tests concern an empirical ensemble probability law, not the true distribution of future weather. Known mathematics (Fréchet-type bounds, moment LPs, information-set nesting, sufficiency of a count distribution, binary cost-loss decisions) is machinery, not a finding. We ask about empirical adequacy and its boundaries on modern stochastic ML and physical forecast fields; no new probability theorem or proof of novelty is promised.

- Leads: 84 and 180 hours, valid at 12 UTC (3.5 and 7.5 days after initialization). This is a synoptic temperature snapshot, not a daily maximum or a heatwave duration. Approximate afternoon timing varies geographically. The main inference is for this temperature endpoint only.
- Six broad centers (latitude, longitude): Iberia (40,-4), France (47,2), central Europe (50,14), Balkans (44,22), northern India (27,75), Sahel (14,2). These are geographical sampling labels, not actual service networks, population samples or regional rankings.

## Quantities and comparison conditions

For a portfolio and threshold, let X_j be its binary site exceedance indicator, S=sum X_j, p_j=E X_j, b_ij=E X_i X_j, and q_k=P(S>=k), with the original fifty equally weighted coherent ensemble members defining these expectations.

1. Site probabilities alone: sharp lower and upper bounds on q_k over arbitrary probability laws on {0,1}^n with the exact p_j. Use an analytic sorted-marginal formula and independently validate it against enumerated linear programs.
2. Site probabilities plus a single aggregate second factorial moment E[choose(S,2)] = sum b_ij: minimize/maximize the event indicator over nonnegative masses on binary states, with normalization and these equality constraints. Site probabilities are still included, so this is stronger than just two moments of S.
3. Site probabilities plus every pairwise co-exceedance b_ij: the analogous complete binary-state LP. Zero/one marginal reduction and exactly zero pair-cell pruning are mathematical simplifications only; preserve all feasible states. The pair matrix permits the aggregate moment to be calculated for any queried subset.
4. Original ensemble count distribution: compute the PMF of S and its tail q_k exactly, separately for each queried portfolio/threshold. It preserves all these capacity decisions by definition, without reconstructing a full joint law. One fixed capacity needs only one tail probability. These are exact query-specific comparators, not discoveries.
5. Independent Bernoulli reconstruction: Poisson-binomial tail from the exact current marginal p_j.
6. Historical-ensemble copula reconstruction: for each model/lead/portfolio separately, rank the temperature members within each of the six preceding scheduled initializations with complete data, stack their rank patterns, and apply the current exact marginal exceedance counts to those ranks. Each historical date supplies fifty coherent ranks per site. Break temperature ties deterministically by member number. Use only earlier initializations and at least three complete prior dates; otherwise mark this baseline unavailable. Do not remove that case from information-bound analyses. This preserves current empirical marginals exactly and borrows past forecast dependence, not observed-weather dependence or a measured calibrated copula. No training/test future leakage.
7. Pair-bound midpoint: (L_pair+U_pair)/2, the elementary minimax probability reconstruction for the compatible interval. Its optimality for worst-case absolute error is analytic. Compare empirical q errors, without claiming it recovers the original joint law.

For n=12 the reusable information schema has 12 marginals plus 66 pairs; the scalar-moment condition adds one number to the 12 marginals. A query-specific count PMF needs 12 independent numbers (13 bins summing to one) and the known-tail query one number. These counts are not measured compressed byte sizes, and information scopes differ. A global pair matrix can be large; no global deployment cost is inferred.

LP feasible masses are arbitrary real probabilities. They are not constrained to be a reordering of exactly fifty equally weighted members. A wide interval therefore means nonidentification over compatible probability laws; it does not by itself prove nonidentification among exact fifty-member permutations. Certification is valid for that narrower class too. Check the distinction directly in the integer sensitivity below.

## Endpoints and analysis fixed in advance

- Main per-case endpoint: width W=U-L of the compatible q interval. This also equals the measure of cost/loss ratios c in [0,1] for which the optimal binary action cannot be certified, under uniform weighting of c; no actual user cost distribution is asserted. Protection costs c, nonprotection loss one if the capacity event occurs, otherwise zero. A weakly optimal action is certified if U<=c or L>=c; when q=c either action is optimal. Numerical comparisons use tolerance 1e-7 and report empirical tie counts.
- Main summaries for n=12: average widths for marginal, aggregate and pair information; paired width reductions; aggregate share of the marginal-to-pair reduction when that total reduction exceeds 1e-7. Report the ratio of summed reductions as the primary share; casewise ratios are secondary to avoid unstable tiny denominators.
- Report the full scheduled complete-case sample AND a prespecified informative stratum: at least four sites have 0<p_j<1 and 0.1<=q_k<=0.9. Neither may replace the other. Also report counts with all sites deterministic, <=2 uncertain sites, q_k=0, q_k=1, and zero marginal interval width. Exact pair identification means W_pair<=1e-7.
- Prespecified decision checks c in {0.1,0.25,0.5}: certification proportion overall and among abs(q_k-c)<=0.1. Report the denominator, tie count q_k=c, and floor/ceiling counts for every comparison. Ambiguity at these illustrative cost ratios does not establish a real operational shortfall.
- Reconstruction outcomes: absolute tail-probability error, action disagreement with the ensemble (zero-regret ties separated), and normalized expected regret under the ensemble law, |q_k-c| for a strictly wrong action, otherwise zero. Compare independence, historical copula and pair midpoint on matched available cases; report missing historical baseline counts. These are information-retention losses under the input law, not observed realized losses or economic value.
- Stratify primary width results by system, lead, geometry and number of uncertain sites. Summaries by center describe sampled geography, not rankings. Report n=4/8 sensitivity. Record observed binary-pattern counts and the number of possible states remaining after exact zero pair-cell pruning, to diagnose apparent identification from finite ensemble support.
- Uncertainty: retain all paired conditions when resampling initialization dates; use a circular moving-block bootstrap of length three scheduled initializations (roughly twelve days), 2000 replications, seed 20261026. Compute ratios from resampled sums/counts. Report percentile 95% intervals, independent-date count and actual denominators. These are descriptive temporal resampling intervals for this fixed convenience sample, not population-representative confidence guarantees. No p-value, causal model comparison or formal superiority test is planned. Member/site/threshold rows are not independent replicates.
- Search and stopping: targeted literature, vocabulary and range are recorded in literature-screen.md; repeat close-work search before submission. Data acquisition attempts the frozen list within the deadline; no statistical stopping on effects. If fewer than twelve initializations have complete matched two-model/two-lead data, describe the main comparative study as undersized/unfinished rather than claiming a general cross-system pattern. A complete forecast file needs all fifty members. Record availability by model/lead/date and retain partial inputs. Main comparisons use matched complete cases; unmatched descriptive results are labeled separately.

## Planned boundary and validity checks

These are prespecified secondary analyses, not exploratory additions.

1. Solver validation: exact analytically solvable deterministic, independent, comonotone, mutually exclusive and higher-order parity constructions; analytic marginal bounds versus full LP; original ensemble always lies in every interval; nested widths never increase; normalization, nonnegativity, primal equality residual, dual feasibility and objective gap checks. Fixtures check code, not social evidence. Log solver versions and options; one CPU thread per solver when feasible.
2. Fixed-ensemble integer check: choose up to 120 informative n=12 cases by sorting SHA-256 of seed+case key, independently of the interval result. Scale equality constraints to integer member counts and solve min/max with nonnegative integer cell counts summing to fifty, for the aggregate and pair conditions. Limit each solve to five seconds, record status/gap and do not equate an unproven incumbent with an optimum. Compare completed bounds to the continuous LP and count unresolved cases.
3. Small moment perturbations: on the same deterministic 120-case subset, relax marginal and pair moment constraints by absolute epsilon=0.005 and epsilon=0.02, with valid [0,1] limits, and compute pair-information interval widths. These are sensitivity sets, NOT sampling confidence sets or actual publication-rounding models. They test whether exact empirical zeros and exact moment precision make apparent sufficiency fragile. No zero-cell pruning is permitted for positive epsilon. Aggregate comparisons under perturbations are not required.
4. Finite member sensitivity: rerun the primary width comparisons with deterministic seeded subsets of ten and twenty-five members (one subset per model/date/lead, shared across all portfolios and thresholds). Compare with fifty; do not present this as validating the ensemble probability law against weather truth. Save selected member IDs.

## Compute, failures, repetitions and stopping rules

All experiments use `scripts/run.py`, which logs code/plan commits, input hashes, command, start/end, exit code and stdout/stderr, enforces at most two concurrent locally started experiment subprocesses, and a maximum timeout of 1800 seconds. Acquisition is split into model/date/lead units or smaller bounded batches. Cache complete fields' selected vectors for restart; no overwrite of completed measurements. A failed unit may be resumed once using cached measurements, under a new experiment ID; preserve both records. HTTP reads allow at most three attempts per byte range, bounded timeouts/backoff, and one advertised mirror fallback; do not perform active scans or load tests. Always check 206, Content-Range, exact byte lengths and GRIB metadata. No silent whole-object download. Network/read errors are missingness, not weather results.

Acquisition, deterministic numerical analyses and 2000 bootstrap replications are the required repetitions above; repeated API trials and human studies do not apply. No API experiments are planned, so API model-price/call-budget plans for measurements do not apply. Total existing API expenditure is reserved in the ledger; only the already completed authorized critique was used.

Check actual clock at milestones. Current deadline is in manifest.json, extended only for confirmed usage-limit stops. Do not start new long experiments with less than sixty minutes remaining. If planned work ends with at least two hours remaining, first investigate alternative explanations and strengthen the same comparisons, then boundary conditions; save a new plan before any unplanned additions and label them exploratory. No new loosely related study. Monitor disk usage (10 GiB including environments/caches) and stop new downloads well before exhaustion. Never leave a single experiment running more than thirty minutes. No subagents, new paid services or model substitution.
