# Plan v2: bounded public-file transfer recovery

This addendum inherits every scientific item in `plan-v1.md` and the unchanged `design-v1.json` (v1 fixed in commit f3e88ecc7fe6676a7dfce69662ee9829c65301db). It changes transport resilience only, before subsequent acquisitions. No metric, exclusion, hypothesis, scheduled date, model, member count or statistical stopping rule changes. Results already acquired under v1 remain v1 evidence.

Reason: the first two AIFS forecast units each encountered a particular 64 KiB range returning HTTP 503 on both advertised public endpoints, despite bounded repeated requests. The first unit's allowed resumption using 32 KiB ranges succeeded. This is an access failure, not a weather result. Replacing missing dates would alter the sample; instead recover the same scheduled fields with ordinary smaller HTTP ranges.

For each fixed requested range, retain at most three attempts per advertised endpoint, as before. If these fail with server error, timeout or a truncated body, split the remaining part of that SAME byte range into two smaller ranges, at most two split levels, with a minimum unresolved range size of 16 KiB. Retain already received and checked prefixes. Do not split after HTTP 403/404 or if a server ignores the Range header. Every subrequest still uses bounded timeouts, checks HTTP 206, Content-Range and exact length, and is logged. This is a bounded recovery of a known public file, not a scan, access-control bypass or load test. No query-string cache busting, authentication change or new endpoint. Keep maximum two acquisition invocations per forecast unit, including the already allowed single cached-data resumption, and the enclosing process timeout <=1800 seconds. Failed second invocations stay missing.

Scientific analyses from v1 are unchanged and remain prespecified. This addendum is a technical deviation after transfer failures; it does not make the main endpoints exploratory. Future experiment records link this addendum's commit and code. The original v1 and its acquisition failures are preserved.
