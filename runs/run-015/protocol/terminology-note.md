# Terminology clarification

Recorded 2026-10-26T05:58:55Z. The scalar used throughout the plans and code is a=E[choose(S,2)]=sum_{i<j}E[X_i X_j]. Its established name is the second binomial moment; it is half the second factorial moment E[S(S-1)]. Earlier plans occasionally called it the latter without the factor one-half. Their displayed formula and implemented information set were consistent throughout and are unchanged. The manuscript now uses second binomial moment. This is a terminology correction, not a changed constraint, hypothesis or metric; old plans remain as committed.
