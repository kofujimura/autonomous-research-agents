Use exactly the native-grid cases selected under v3. Define one fixed interior subset per case: each pixel's full 3×3 neighborhood must be in the five-year common valid agricultural population, and the nine reference broad-group labels must agree within each year (agreement across different years is not required). Exclude the outer raster row/column. This erodes broad-group boundaries by one pixel; it neither removes crop turnover within fields nor uses prediction quality or diversity changes for selection. For this same subset, compare the saved frozen logistic predictions at the center and at one native pixel north, south, east and west. These are 10 m perturbations, a stress test rather than an estimate or correction of actual misregistration. All neighbor predictions already exist in the full population because of the common-neighborhood eligibility. No additional downloading, model fitting, taxonomy changes or AI calls are needed.
