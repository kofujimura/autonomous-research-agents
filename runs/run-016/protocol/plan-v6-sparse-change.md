# Exploratory revision v6 — sparse changes, interval checks and stratified references

This plan is added after inspecting two actual-target pipeline-check units, before the full 30-landscape inference. It is exploratory relative to v1, and does not change the original primary outcomes, fixed cases, frozen models, budgets or comparisons. Preserve and report the original results.

## Motivation and scope

In the two available pipeline units, paired direct sampling had much smaller MSE than independent sampling, yet nominal 95% coverage was 0.708 and 0.848 at the preselected illustrative budget n=128. Model-assisted paired estimates had wider intervals, coverage 1.0 and no direction reports in those cases, with frequent simplex projections. These are two transitions from one landscape with small nonzero reference changes, not complete-cohort findings. Subsequent inspection found that only about 2–2.5% of its locations changed broad crop labels, so a sample of 128 contains few changed locations. The zero-change event explains only part of the observed coverage loss. This motivates checking sparse changes and stronger comparisons across all fixed test landscapes, without selecting places by this outcome.

## 1. Sparse-change diagnostics and an exact coverage ceiling

For every original broad-taxonomy primary unit/budget, count M locations with different reference labels between years and the number changed in each saved paired audit sample. Tabulate interval coverage, standard-error zeros, reporting and wrong reporting by observed changed-count bins 0, 1, 2, 3–4 and >=5, and show the underlying denominators. Compute exact P(no sampled changes)=choose(N-M,n)/choose(N,n). For the paired direct estimator, no sampled changes implies identical estimated proportions and influences, hence a zero-width interval at zero. When the true entropy change is nonzero its coverage is therefore at most 1-P(no sampled changes). For true zero changes the ceiling does not apply. Count cases in which this ceiling is below 0.95 and compare to actual coverage. This algebraic consequence is not a novel empirical result; the empirical questions are its frequency and how much failure remains outside that event. Keep all cases, including true zero changes.

## 2. A finite-population reference envelope and a narrow guard

Invert the exact hypergeometric CDF for the observed number of changed sampled locations to obtain a one-sided 95% upper confidence bound on the finite-population change fraction tau. Check inversion on small finite populations by exact enumeration. Since total variation between the annual class proportions is at most tau, apply the verified classical entropy-continuity bound B(tau)=tau*ln(K-1)+h(tau), capped at ln(K) for tau >=1-1/K. The resulting envelope [-B(tau_upper), B(tau_upper)] is conservative and always includes zero; it is an uncertainty reference, not a direction-detection method.

For the original paired-direct interval, also evaluate a minimal guard: when no sampled reference labels changed, take the union with that envelope; otherwise retain the original interval. Its point estimates and direction reporting in the zero-change event are unchanged, so an increase in coverage alone is not an improvement in direction detection. Measure remaining undercoverage and do not claim a uniform 95% guarantee for this mixed procedure. Compute from exactly the original saved draws, all five budgets and both representations where needed; direct estimates are representation-independent. Save raw bounds/coverage.

## 3. Jackknife comparison at the preselected illustrative budget

At n=128, compare delete-one jackknife bias-corrected entropy changes and jackknife standard errors for direct/model-assisted and paired/independent designs, both frozen broad logistic representations. Delete a pair of locations in paired samples; use separate delete-one variances for independent samples. Each leave-one-out estimate keeps the population prediction mean fixed, recomputes sample residual means and simplex projection, then entropy. If d is the full-sample entropy change and d_-i the delete-one changes, use d_J=n*d-(n-1)*mean(d_-i); variance (n-1)*mean((d_-i-mean(d_-i))^2), with the same finite-population correction. For independent samples add year-specific jackknife variances. Do not truncate bias-corrected changes to the entropy range. The comparison addresses estimator bias/nonlinearity, but resampling cannot discover an unobserved type of change. Report MSE, coverage, reporting, wrong reporting and zero standard errors, with saved raw values. No guarantee is assumed and the original methods remain primary.

## 4. Stratified reference-sample comparison

Use predictions for sampling as a stronger established design comparison, rather than only as residual adjustments. For each frozen broad logistic representation and primary transition, rank population locations by L1 distance between their two annual probability vectors; the highest ceil(N/4) form one stratum and all remaining locations form the other. Break exact ties by original saved population index. This construction uses predictions, never reference change labels. Save the stratum indices, population sizes and actual reference-change fractions for interpretation.

Allocate half of each annual budget n in {32,64,128,256,512} to each stratum. Draw without replacement within strata; compare revisited and independent annual samples with 500 replications. Common random draws compare direct and model-assisted estimates within each representation. Seeds derive from 16016/stratified/representation/landscape/year-pair. Strata may differ by representation, so direct estimates in this supplement are not assumed identical across representations.

Use population stratum weights W_h=N_h/N. Direct proportions are sum_h W_h*sample_mean(onehot Y). Model-assisted proportions are population_mean(P)+sum_h W_h*sample_mean(onehot Y-P). Project only as in v1. For paired intervals sum W_h^2*(1-n_h/N_h)*sample_variance(phi_b-phi_a)/n_h over strata; for independent intervals sum the two year-specific variances within each stratum. Use the same estimated gradient, tolerance and reporting rule. Compare MSE, nominal coverage, reporting, wrong reporting and projection with the original unstratified design at the same number of labels. Also count no-change samples and design-exact no-change probabilities. This is a post-diagnostic exploratory comparison, not a new sampling theorem or a cost comparison of field visits. The highest-change-probability stratum is not selected using true changes or the observed method benefit. Retain negative results.
