# Exploratory scope extension v7 — complete declared agricultural reference frames

Added after the two-unit pipeline check and numerical validation of v6, before the complete main embedding-based inference. It deepens v1's whole-support-versus-sampled-reference check. It does not replace the original common-feature populations or the three native-embedding cases. All results under this extension are exploratory.

## Why this check

The main comparison conditions on an initial sample of 4,096 declared agricultural pixels and then common five-year feature availability. The full reference rasters are already saved for every selected test landscape. Reference-only sampling can therefore separate the sampling-design behavior from that initial downsampling and from a particular representation's missing values, without more downloads or new fitted models. It cannot establish a model-assisted result on a full population without full predictions.

## Fixed frames and comparisons

Use all thirty original test landscapes; do not add, replace or select cases by their changes or inference performance. For each, compare (A) the original 4,096 reference points before any embedding missingness exclusion and (C) every native 10 m pixel in the five-year stable agricultural reference support. The original common-feature point frame (B) remains the main analysis and is compared once complete. The three preselected common-feature native frames (D) remain the model-assisted scope checks. These letters are only file bookkeeping; describe the frames in words in the paper.

Use both published broad and fine agricultural taxonomies, on identical spatial supports. Retain every category in their source mapping and every small/zero change. Compute exact reference proportions/entropy changes, reference-change fractions, floor/single-group counts and known-population influence variance diagnostics. For the complete stable support also compute the already specified first-phase reference-only linearization term for a 4,096-point initial sample. It is not an unconditional two-phase coverage estimate.

Run direct reference sampling only, paired and independent, on the same three primary transitions, budgets 32,64,128,256,512 per year and 500 replications. Use v1's estimator, entropy, gradient, finite-population correction, approximate interval and direction rule. Save all per-trial estimates, standard errors, coverage and wrong-direction outcomes. Draw uniform samples without replacement. Derive seeds from 16016/reference-frame/frame/landscape/year-pair. Share the saved draws across the broad and fine taxonomies; use uint32 when the full frame exceeds 65,535 points. The two frames have different populations and independently generated samples; comparisons of their true changes are deterministic, whereas estimated Monte Carlo summaries have simulation error.

Summarize equal-weight landscape/transition results, Monte Carlo error, paired/independent MSE ratios, reporting/abstention, wrong-direction rates, exact no-sampled-change probabilities and observed zero-change samples. Preserve zero standard errors and all unfavorable results. The complete-support reference result is not a national probability estimate or an independent geographic replication: it uses the same thirty selected landscapes. Declarations remain intended primary use, not realized harvest observations; changing agricultural extent remains excluded. Both reference taxonomies include grassland/permanent agriculture and are not counts of biological species.

No new API use, data retrieval or human experiment is involved. Save input label hashes, synthetic draw construction/seeds, raw draw files shared across taxonomy levels, raw outputs and commands. Use the two-slot runner and 1,800-second timeout. Code is committed before execution. Stop before storage/deadline limits; do not begin a long new process with 60 minutes left. If unfinished, report which frames/taxonomies ran without substituting them for the main study.
