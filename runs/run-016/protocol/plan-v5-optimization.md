# Revision v5 — source logistic optimization

This revision incorporates v1–v4 and is fixed after the first source logistic fits, before any test diversity change, classification outcome or audit-inference outcome has been examined. It changes the numerical iteration budget, not regularization, tolerance, training data, feature masks, taxonomy, sampling, metrics or stopping rules for acquisition.

In E08-source-logistic, three of four source fits reached the fixed 1,000-iteration limit with a ConvergenceWarning: broad TESSERA and both fine-taxonomy fits. Broad AlphaEarth stopped without a convergence warning at 699 iterations. The source support has 81,858 training and 40,958 calibration points; all planned source landscapes are included. Their predictions, coefficients, calibration matrices and diagnostics are retained under results/source-models/. A completed process exit is not a claim that those three optimizations converged.

Increase the maximum to 10,000 iterations for all four logistic fits, preserving C=1, tolerance 10^-5, lbfgs, source-only standardization, unweighted labels and seed. Fit from the same deterministic initialization on the same committed source manifest, and save separate outputs under results/source-models-v2/. Record all warnings/iterations. This is a numerical correction motivated by observed source convergence failure; it is not chosen by target performance or diversity-change results. Keep the v1 stopping-budget fits available for an optional comparison. The revised frozen heads define the primary prediction maps if their optimization stops without a convergence warning. Do not silently relabel the first fits as converged.

If a revised fit still reaches the limit or a process times out, retain it and report the attained numerical limitation. A further change requires a new version and a reason. Refreshed logistic diagnostics, if run, use the same revised 10,000 maximum for consistent optimization. Random-forest robustness remains as preplanned after primary logistic convergence. No hyperparameter search or new AI call is authorized or needed.

Each source-fit process remains bounded by the 1,800-second runner. Data downloads may use the other experiment slot, with disjoint extraction shards when two acquisition jobs run. Do not start another experiment above the two-process limit. All original results remain referable.
