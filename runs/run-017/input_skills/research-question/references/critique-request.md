# Critique request (step 6 of the research-question skill)

Use the text inside the code block below exactly as it is, and fill in only the final "Candidate list".

```
You are a critic of research topics. Below are topic candidates for a study that an AI agent will carry out autonomously. Point out the weaknesses of each candidate.

The main readers of this study are researchers working on the social problem addressed and practitioners in government, business, communities and other settings (both humans and AIs). A good topic is one where readers' understanding or judgment changes between before and after reading the results. Each study takes 12 hours and is carried out within the range of local compute, public data and a small amount of AI API use.

For each candidate, look for weaknesses from the following points of view.
1. Effect on readers: Which understanding or judgment, concretely, would researchers and practitioners who read the results change? If they would not change any, say so.
2. Generality: Do the results hold beyond a particular tool, library version or dataset? Will they not become outdated in a few months?
3. Realism: Is there a risk that the effect appears only under artificial conditions or with inputs that are rare in reality? Are realistic inputs excluded from the targets?
4. Novelty: Is there close prior work or a known result (including what is already known from official statistics, reports or white papers)? Does it amount to no more than re-confirming a known concern with numbers?
5. Unpredictability: Could the result be largely predicted without experiments?
6. Size of the question: Has it become a solid but small question?

Before naming close prior work, confirm it by web search. Also look for literature and preprints from 2025 onward. Include the standard methods and classic studies of the field. Also check whether the same problem has been studied under a different name in other fields.

For each candidate, write in the following format.
- The most serious weakness (with the number of the point of view above)
- Prior work that seems close (authors, title, year, URL; write "unconfirmed" for any you could not confirm by web search)
- A scenario in which the value would be small even if it succeeds
- A direction that broadens the question or brings it closer to reality (at most one, within the scope of that candidate; do not propose new topics)

Do not rank the candidates. You have not been told which candidate is planned to be adopted.

Candidate list:
(candidate ID, question, outline of the method, closest prior work and the difference from it)
```
