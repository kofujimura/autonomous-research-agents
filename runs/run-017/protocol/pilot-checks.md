# Topic-selection pilot checks (before main study)

The three pilots below are feasibility checks under step 4. They are limited to 15 minutes each, including data/tool checks; each child process will be timed out. They do not establish the study's claims. Any downloaded input reused later will be identified in the main plan. Results-based hypotheses or choices will be labelled as pilot-informed.

- P01 / C03: Attempt an ordinary public range read of one annual satellite embedding tile around the Minnesota prairie/forest transition and obtain wetland reference polygons and their licence/date documentation. Assess whether the region contains enough small wetlands and whether embedding values can be decoded. Do not compare mapping methods or select outcome thresholds here. Stop after access and scale are demonstrated, or 900 seconds.
- P02 / C01: Confirm whether historical GenCast ensemble trajectories can be obtained without an account, new paid billing route or local full-model inference. Inspect official access/deprecation documentation and one public data endpoint if documented. No proxy data substitute; stop on inability to obtain a usable public archive, or 900 seconds.
- P03 / C06: Obtain a small public aggregate electricity demand series with reuse terms and inspect availability of a small locally executable Chronos model. Run a tiny forecast only if model and input are obtainable within the pilot period; otherwise report access-only or failed feasibility. Do not use outputs as main-study evidence. Stop after 900 seconds.

No human-subject data, participant experiments or third-party security testing is involved. Public environmental and energy data are covered by start instructions §12.5.
