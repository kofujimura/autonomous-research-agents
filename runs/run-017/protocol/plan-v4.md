# Main protocol v4: pre-performance controls for class composition

The original primary H1 contrast, five original policies, representations, metrics and repetitions remain controlling. The additional comparisons are secondary and pre-performance, rather than replacements for the planned main analysis.

Reason: the two-stage proposal and uncertainty policies can acquire different class counts from a 50:50 area sample. A common FPR removes the direct effect of choosing a probability cutoff, but it does not guarantee that fitting with different class counts learns the same ranking. The October 2026 boundary-aware AEF wetland preprint also emphasizes prevalence and threshold dependence. Address the potential alternative explanation rather than attributing all practical-policy differences to object coverage.
