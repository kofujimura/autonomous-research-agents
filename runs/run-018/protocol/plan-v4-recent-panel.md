# Exploratory supplementary panel selected by source-image recency

This is an **exploratory expansion** triggered by inspecting the original fixed panel's imagery-date metadata (analysis/label-vintage-initial.json), not by matching performance. At fixing time no model fit or regime-agreement output has been observed. It does not replace the original twelve windows, alter their primary estimand or erase old/failed records. Plans v1–v3 continue to govern the primary study.

Motivation: only141 of3667 selected wetlands in the initial convenience panel have source IMAGE_YR>=2020. Agreement with much older imagery labels could reflect landscape change as well as representation/matching quality. The predefined recent subgroup may therefore be too limited to assess this explanation. A supplemental recent-inventory panel can test a boundary condition, without identifying a causal effect of label age or supplying field validation.

Select at most six additional windows by **image-project metadata alone**, with no wetland category/count or embedding outcome used to choose their centres. Fixed anchors, in this order: R01,R03,R04,R06,R09,R12. For each anchor query the public NWI ImageYear layer for projects with IMAGE_YR>=2020 intersecting a +/-400km UTM envelope. Save original query responses, URLs, times and hashes. Interpret project geometries in anchor UTM; erode each by11.5km so a16km square can fit. Remove25km discs around all original window centres and any supplementary centres already chosen. For each remaining project find the nearest point to the anchor within the eroded geometry; choose the smallest distance <=400km, ties by project OBJECTID. No qualifying project means an unfilled slot, not a different anchor. Snap centre as in v1, record original project/year/distance and fix the resulting S01–S06 panel file in Git **before** fetching wetlands there.

Apply the same NWI eligibility, geometry audit, 1200-polygon hash cap, raw3x3 embeddings, 2024 products, hydrological features including HAND, spatial roles,1km training buffer, candidate pool, models and metrics as v1–v3. Save recency coverage; do not assume all point labels inherit that year without the metadata join. Keep all selected windows even sparse. Use a separate feature file and separate fits on supplementary-panel training blocks only; do not add its training labels to the original primary fits. Distinct landscapes and training sample sizes mean any differences between panels are descriptive boundary evidence, not an isolated age-treatment effect.

Primary comparisons within this supplement remain the augmented pair learner versus both hydrological learners at50% coverage, and rawcosine/decoder diagnostics. Report all originally specified methods where executable. Bootstrap supplementary regions only if >=4 analysable windows; otherwise descriptive. Mark all supplemental-panel effects exploratory in claims and the paper. The original primary results retain their planned status.

Acquisition/compute limits and safety remain unchanged. At most two experimental processes, each1800s; all data public and reusable, no newAI or paidAPI. Stop at six slots, fixed exclusions orresource/deadline limits. Source-image recency remains a proxy for inventory timeliness; no current hydrological truth, users or outcomes are measured.
