# Reporting specifications fixed before matching results

These implement and clarify v1–v3; the recent-panel outputs remain exploratory under v4. The fixing event/commit precedes any matching execution.

- Four rotations give one query prediction per retained wetland, with shared training/reference data across rotations; do not describe them as four independent repeats. Selection is within window/rotation, floor(coverage*n), ordered by descending confidence then queryOBJECTID. Aggregate numerator/denominator across rotations within region, then average region risks. Empty pools and groups retaining zero queries are counted and do not produce fabricated zero risks.
- Main table:50% nominal coverage, achieved counts/coverage, mismatch risk pooled and region-macro,95% region-bootstrap interval. Primary differences are augmented-pair risk minus each of the two hydrological-learner risks (negative favours augmentation), paired across the same regions. Report both single representations and combined secondary, without selecting a winner after inspection. Bootstrap10,000, seed18018; fewer than4 comparable regions means no interval.
- Uniform-reference chance risk is the analytic mean of within-pool mismatch fractions. Under a uniformly random fixed-budget query screen its expected risk equals the all-query mean; report this as an expectation, without pretending a confidence-ranked random method was deployed. Oracle uses evaluation labels and is explicitly nondeployable.
- Report pool counts: empty, single-category/all-correct, single-category/all-wrong, multi-category with correct class available, and no correct class available. Also report support of query classes in retained training data locally/globally. Full-coverage results and class distributions expose majority-class effects.
- Nontrivial-matchable subgroup uses each method's original screened set and reports its actual subgroup coverage; do not rescreen using labels. Its denominator may differ across methods. No unqualified paired inference from unequal conditional cohorts.
- To distinguish ranking from abstention, report every method on the **same queries selected by the hydrological pair learner** at50%, and separately on the hydrological decoder's screen; full-coverage rankings are another common-query comparison. These planned diagnostic contrasts do not replace the primary complete-pipeline metric.
- Count overlap of chosen reference IDs for each augmented pair method and each main comparator on all nonempty queries, plus overlap of screened query IDs at50%. These are counts of cases where methods actually make different choices, needed to interpret small increments and structurally identical inputs/outcomes.
- Descriptive risk and achieved coverage by query regime, vegetation, image-date group and polygon size accompany the main table. They diagnose whether an overall advantage is obtained by screening out an entire difficult category. They are not calibrated fairness guarantees or causal subgroup effects.
- Preserve exact probabilities/float64 values in intermediate files. Round only in generated display tables/figures/paper substitutions; do not manually transcribe numerical results into prose.
