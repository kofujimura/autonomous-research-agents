# Protocol v3: strengthen explicit hydrological covariates before fitting

This supplements v1 and v2. Fixed before any learned fit, nearest-neighbour matching, regime-agreement result or effect estimate. All prior versions remain unchanged.

A further close-work full-text check obtained Ryan et al. (2026), *Streamlining Wetland Vegetation Mapping with AlphaEarth Embeddings*, and Askew et al. (2025), *Development and application of a hybrid terrain–multispectral image model of floodplain hydroperiod*. Their methods explicitly use hydromorphological predictors; Askew's methods and results use height above nearest drainage (HAND). Comparing embeddings only to local elevation/slope/topographic position could therefore omit a standard relevant predictor. Strengthen the primary public-data baseline **before** seeing results.

Add the **Alaska Satellite Facility Global 30m Height Above Nearest Drainage, v1 / 2021 DEM release**, public COG distribution. Official README and AWS open-data registry were checked in full: research/derived-data reuse is CC0 1.0; acknowledge ASF and its underlying Copernicus source as stated. The product is generated using D8 routing, pit/depression filling, flat resolution, flow accumulation, a drainage-mask threshold and HAND calculation. It derives from the Copernicus surface DEM, so canopy/building artifacts and drainage-mask assumptions remain limitations; it is not a field-based groundwater or water-source measurement. Do not infer identical height accuracy to USGS bare-earth terrain.

Acquisition: use official tile naming/metadata, save every source pixel window used and its geotransform/no-data value, then bilinearly reproject to the same saved 30m UTM grid. Negative/nonfinite HAND values are missing, never silently changed to zero. Tile seams are handled by valid-value mosaicking; retain source records and counts. Save whole buffered windows needed by offline recomputation, not global tiles. All sites remain fixed. If HAND fails in a region, median imputation with a training-only missing indicator is allowed as for other individual covariates; explicitly count/report regions and wetlands with missing HAND and show a sensitivity restricted to observed HAND. Do not replace sites.

Added primary features, derived from `log(1+HAND metres)`: centre value, mean and standard deviation in 90m, mean and standard deviation in 510m (five features). All primary hydrological distances, pair learners, decoders and augmented methods include these five alongside v1 features. The main hypothesis and comparison rule are unchanged: meaningful incremental advantage must survive **both** hydrology pair and hydrology decoder comparisons. The v1/v2 feature set without HAND becomes a planned secondary baseline-strength diagnostic, retaining the same cohort, splits and other hyperparameters. Its exclusion is available as an explicit analysis flag; no test-based baseline selection.

No separately thresholded local flow-routing approximation is substituted for HAND. Public NHDPlus elevation-derivative metadata was considered as an additional flow-accumulation source, but the public catalogue returned403; no restricted route was accessed and this source is not required for the main design. Soil properties, groundwater levels, current gauges and field HGM assessment remain unmeasured. This is a strong specified **public covariate** comparison, not a claim to represent the best possible hydrological model.

Reason for timing: a newly obtained relevant full-text source exposed an avoidable baseline weakness. The amendment is prospective with respect to all matching results. The event and fixing commit are recorded in events.jsonl. No human scientific advice was received.
